# Pixl-Personal-Builder-Page
My personal builder page for the Hack Club event Pixl: made from HTML and CSS, some minimal JS. AI was not used. 

Hello! This is my personal builder page! It shares some info about me and my coding. It's my first project for Pixl. There are two cards, one on the left that just has my name, github, handle, and one of my projects, and one on the left that shares some things about me. The card on the left can be clicked on to display a couple of my projects!
